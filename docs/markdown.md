# MarkdownのDocリンク

本文やコメントに `[[practice_common_description]]` と書くと、`practice_common_description` を表示する `/pages/practice_common_description` へのリンクになります。DocのスラッグまたはIDを指定してください。たとえば `[[123]]` のリンク先は `/pages/123` です。タイトルからの検索や、リンク先の存在確認は行いません。

入力中のプレビューでも保存後の本文でも使えます。リンク先は同じタブで開きます。

- `[[AAA]]` は、文字の大小を変えずに `/pages/AAA` へリンクします。
- コード中の記述や、`\[[AAA]]` のようにエスケープした記述はリンクになりません。
- 空、空白だけ、改行を含む記述、閉じていない記述、および `[[.]]` と `[[..]]` はリンクになりません。
- 通常のMarkdownリンク・画像を優先します。`[[AAA]](/other)` は、`[AAA]` を表示する `/other` へのリンクです。リンクのラベルや画像の代替テキスト内の `[[AAA]]` は従来どおり表示します。
- メール通知とAtomフィードではサーバー側の `md2html` を使うため、`[[AAA]]` はそのまま表示されます。変換するのはアプリ内プレビューと保存後のJavaScript表示です。
